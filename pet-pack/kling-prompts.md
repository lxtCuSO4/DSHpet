# 可灵（Kling）出片手册：3 段绿幕视频

> 目标：产出 3 段 **16:9 / 纯绿 #00FF00 / 零位移 / 首尾帧一致** 的视频，丢进 `_repo\video\`
> （文件名就是最终动画名，例如 `待机呼吸.mp4`），然后 `build.cmd -Name <名>`。
>
> 原始配方见仓库 `prompts/桌面宠物 10 秒动作提示词.md`（含 60+ 个动作）。下面是从里提炼的
> **可灵可用版**：把"长规范 + 按秒拆解"压成一段能塞进输入框的提示词，因为可灵的单条提示词
> 过长会稀释动作描述，而**边界/绿幕/零位移这些硬约束才是决定成败的部分**。

---

## 0. 生成参数（先设对，再谈提示词）

| 项 | 选什么 | 为什么 |
|---|---|---|
| 模式 | **图生视频**（有形象图时）/ 文生视频 | 图生视频能把你的角色原样带进来 |
| 首帧 | 你的**绿幕形象图**（见第 3 节） | 保证 3 段视频是同一个角色、同一站位 |
| 尾帧 | **同一张首帧图**（可灵 1.6/2.x 支持首尾帧） | 自动闭环，循环播放不跳帧 |
| 时长 | 待机 **10s**；点击/拖拽 **5s** | 点击与拖拽是打断式短动作，5s 足够且便宜 |
| 画幅 | **16:9**（1280×720 或以上） | `chroma_step02` 按 1280×720 处理，竖屏会被压扁 |
| 运镜 | **固定 / 无运镜** | 任何推拉摇移都会让角色漂移、脚底错位 |
| 水印 | 会员去水印，或后期裁 | 有水印会被抠进角色身体（见第 4 节） |
| 种子 | 三段用不同 seed，但**同一张首帧** | 角色一致靠首帧，动作差异靠 seed |

## 1. 通用块（每段提示词都以它开头）

```
16:9 横屏，全画面纯绿幕背景，颜色严格为 #00FF00 单一纯色，无渐变、无阴影、无地面、无任何杂物。
Q版卡通角色【蓝灰色长发、白色蕾丝连衣裙、深棕色蝴蝶结、白色小花发饰、黑色小皮鞋】，全身正面站立，居中偏下：
头顶位于画面高度 20% 处，脚底位于画面高度 85% 处，身体左右边缘在画面宽度 25%~75% 之间，
角色四周始终保留至少 10% 画幅的绿色安全边距，任何部位和道具都不出画、不贴边。
全程双脚落点固定在画面正中，不允许任何左右或前后位移，只允许原地动作（轴心转、原地跳、脚尖点地）。
固定镜头，不推拉、不摇移、不缩放。画面中只有这一个角色，无文字、无字幕、无 logo、无背景音乐画面元素。
最后一秒必须回到与第一帧完全一致的正面站立姿势。
动作：
【这里是第 2 节的具体动作描述】
```

## 2. 具体动作（把这段接到上面"动作："后面）

### A. 待机呼吸（`待机呼吸.mp4`，10s，`animations.idle`）

```
0~3 秒：原地自然呼吸，身体以极小幅度上下起伏，双臂自然垂放，每隔约 2 秒轻眨一次眼。
3~7 秒：头部以极小幅度向左、向右缓慢环顾，头发与配饰随之柔和摆动，身体重心始终留在原地。
7~10 秒：头部缓缓回正，呼吸恢复平稳，回到标准正面站立。
要求：起伏幅度很小，像站着发呆，不要有明显走路、挥手或转身。
```

> 待机是**唯一会被反复播放**的动画，所以"末帧=首帧"最重要。要 10s，是因为 24fps 下
> 太短的循环会看出明显的周期感。

### B. 点击回应（`点击回应.mp4`，5s，`animations.clicks`）

```
0~1.5 秒：身体略微下蹲蓄力，视线朝上，双臂微张。
1.5~3.5 秒：双脚发力原地垂直向上轻跳，最高点双手高举做欢呼状，脸上露出笑容，头顶弹出半透明爱心特效。
3.5~5 秒：自然落回原处，膝盖微曲缓冲，站稳后双手放下，恢复标准正面站立。
要求：只在原地垂直弹跳，不横向移动，跳跃最高点头发也不碰画幅顶边；爱心特效在结束前淡出。
```

> 点击动作**随时会打断**，所以起手就要有反应（前 1.5 秒必须已经在动），不要做慢热。
> 5s 版更适合；若你的账号只有 3s，删掉蓄力段，直接"跳一下+落地"。

### C. 被抓起悬空（`被抓起悬空.mp4`，5s，`animations.drag`）

```
0~1.5 秒：像被无形的手从上方抓起来，身体突然离地僵直，双脚悬空，四肢自然下垂，头部轻微偏斜。
1.5~3.5 秒：保持悬空，身体随惯性轻微左右晃动，表情疑惑呆萌。
3.5~5 秒：悬空感减弱，身体缓缓下降，双脚平稳落回原地，恢复标准正面站立。
要求：全程在原地上下浮动，不横向漂移、不旋转；脚底离画幅底边始终保留安全距离，不触碰底边。
```

> 这 3 段就够跑通了。想更"活"，再加 `东张西望`（turn）、`挠头`/`伸懒腰`（categories），
> 提示词骨架完全一样，只换动作段。

## 4. 关键：用心爱的形象图（图生视频）

**能复用，但要过一道"绿幕化"**，因为可灵不会替你换背景，而抠像脚本只认绿色。

流程：

1. **准备形象图**：全身、正面、脚完整、背景**纯色或透明**、角色不贴边。半身图不行——脚会被生成出来，通常很糟。
2. **压成绿幕首帧**：
   ```bat
   python pet-pack\sticker-to-green.py 我的角色.png -o 绿幕首帧.png
   ```
   - 原图已是透明 PNG（带 alpha）→ 直接合成到 `#00FF00`
   - 原图是纯白/纯灰/纯色底 → 脚本取样边框颜色自动抠掉（`--key auto`，默认）
   - 底是复杂场景 → 先 `pip install rembg` 或走 remove.bg 抠成透明 PNG，再来这一步
   - 输出固定 16:9（1920×1080）、立高约 65%、脚底 85%、水平居中——正好是第 1 节要求的构图
3. **同一张 `绿幕首帧.png` 当三段视频的首帧**（能设尾帧就设成同一张）。
4. 生成时**只改"动作："那一段**，前文一个字都别动——这才是三段之间角色不变的关键。

### 实测会遇到的四个坑

| 现象 | 原因 | 处理 |
|---|---|---|
| 角色被重新画成别的样子 | 图生视频重绘权重过高 | 尾帧也钉同一张图；时长压到 5s；提示词里加"保持首帧角色的脸、发型、服装完全不变" |
| 角色慢慢"飘"向一边 | 模型自身漂移 | 提示词强调零位移；**别用运镜**；必要时后期 `--center` 让 `normalize` 兜底（它本来就按 alpha 重心重新居中） |
| 角色边缘一圈白 | 抠图残留/描边 | 绿幕首帧别贴白边；实在有白边，出片后加 `--erode 1` 收紧 1px（见脚本 `--help`） |
| 动画里角色尺寸忽大忽小 | 模型推拉镜头 | 运镜锁死；`normalize_step03` 虽会统一站立高度，但**帧间的缩放它救不了** |

> 想要"绝对不变形"的兜底方案：用这张绿幕图做一段 **静止 1 秒的 webm** 当 idle，
> 先用静态桌宠跑通全链路（`sticker-to-green.py --static-webm`），再逐步换成 AI 动作。

## 5. 出片前自查（30 秒）

- [ ] 16:9，纯绿背景，四角都是绿
- [ ] 角色头顶离顶边 ≥15%、脚底离底边 ≥10%、左右各 ≥10%
- [ ] 第一帧和最后一帧是同一个站立姿势（循环不跳）
- [ ] 全程脚底线基本不动（±5% 以内）
- [ ] 无阴影、无地面、无文字水印
- [ ] 帧率 24 或 30（30 也能用，`encode` 会转 24）
- [ ] 文件名 = 配置里的动画名，例如 `待机呼吸.mp4`

过完自查，把这些 mp4 放进 `_repo\video\`，跑：

```bat
pet-pack\build.cmd -Name mypet
```

**如果视频没有水印，别加 `-Watermark`**（默认就不加）。加了会把"水印遮罩位置的像素"当水印涂掉，
在干净的画面上挖出一块补丁。

流水线会打印每段的 `scale`（归一化缩放比）。三段之间 scale 差异大（比如差 20% 以上），
说明 AI 生成的体型不一致，最好重生成，否则换动画时会"忽大忽小"。

## 6. 换用国内平台（阿里万相 / 即梦 / 豆包）

三家都能满足我们要的唯一硬指标——**图生视频（能上传首帧）**，参数几乎一样，只改设置项的名字。
本仓库这一版的三条素材（待机/点击/拖拽）实际是用 **阿里万相** 出的，见 6.4 的实测记录。

### 6.1 设置项对照（三家通用）

| 项 | 怎么设 | 说明 |
|---|---|---|
| 生成模式 | **图生视频**（首帧 / 首尾帧） | 纯"文生视频"没救——角色会重新瞎编 |
| 首帧图 | `pet-pack\_art\green-frame.png` | 三段**用同一张**，这是角色一致的关键 |
| 尾帧图 | 同一张（有首尾帧模式时必选） | 循环不跳帧的保险 |
| 画面比例 | **16:9** | 竖屏/1:1 会被 normalize 压扁 |
| 时长 | 待机 **10s**，点击/拖拽 **5s** | 只有 5s 档也能用（见 6.5） |
| 分辨率 | 720P / 1080P 都行 | 流水线会统一成 1280×720@24 |
| 运镜 | **固定 / 无运镜**（有"智能运镜"就关掉） | 一推拉角色就漂移、脚底错位 |
| 运动幅度 / 灵动性 | 待机调中档，点击/拖拽调最低~中 | **调最低会把动作压死**，见 6.4 |
| 种子 | 三段不同 | 同一张首帧已经保证角色一致 |

平台入口：阿里万相 <https://tongyi.aliyun.com/wanxiang>｜即梦 <https://jimeng.jianying.com>｜豆包 App 的视频生成

### 6.2 提示词怎么放

图生视频的输入框比可灵简单：**一个描述框 +（部分版本）反向提示词**。所以：

1. 把第 1 节「通用块」里**绿幕 / 构图 / 固定机位 / 零位移 / 末帧回到首帧**那几句整段粘进去（必须的）；
2. 再粘第 2 节对应动作的按秒描述；
3. 有反向提示词框就粘第 3 节整段；没有就跳过（正向提示词里已经写了"不要"）。

图生视频已锁死角色长相，通用块里那句"角色描述"可以删掉，把长度省给动作描述——
提示词过长会稀释动作。

### 6.3 水印

免费额度出片基本都带角标（**阿里万相**、即梦、可灵都会加）。处理办法：

- 水印压在**绿背景**上 → `build.cmd -MaskBox <x,y,w,h>` 涂绿，对抠像零影响（`-MaskBox auto` 会自动探测）
- 水印压在**角色身上** → 该段重生成，或出片时让角色别占右下角

### 6.4 实测记录：阿里万相（这三条素材的来源）

- **能力**：万相支持图生视频（首帧），本次三条都是 1920×1080 @30fps，10s / 5s 两档都能出。
- **水印位置是固定的**：1920×1080 下恒为 `x[1545..1872] y[911..1032]`（328×122，纯白 `[255,255,255]`），
  三条视频、跨帧坐标一字不差 →
  ```bat
  pet-pack\build.cmd -Name mypet -MaskBox 1545,911,328,122
  ```
  同尺寸再出片可以直接复用这个矩形；尺寸变了就用 `-MaskBox auto` 现测。
- **动作幅度要专门盯**：万相画面极稳，但"运动幅度/灵动性"调到最低时会把待机压成**近乎静止的图片**
  （实测帧间差 0.59/255，桌面看像一张会抖的贴图）。待机那条建议调中档，并在提示词里写死幅度：
  「肩膀与胸口上下起伏约身高 1.5%，约 2 秒一次」。
- **构图**：万相出的脚底常在 90~95%（贴底），`chroma_step02` 之后由 `normalize_step03` 重排到 85%，
  只要没出画就没问题；头顶低于 15% 才要重生成。

### 6.5 免费额度只给 5s 怎么办

配置里没有"时长"概念——插件只是循环播放，所以 5s 完全够。三档：

- **A. 直接用 5s**（最省事，循环感略强）
- **B. 用同一张首帧、不同种子生成两条 5s，再拼成 10s**（推荐，拼接点落在"标准正面站立"上，接缝看不出）
  ```bat
  ffmpeg -i A.mp4 -i B.mp4 -filter_complex "[0:v][1:v]concat=n=2:v=1:a=0" -c:v libx264 -crf 14 待机呼吸.mp4
  ```
- **C. 慢放**：`setpts=2.0*PTS`，等效 12fps，有顿感，不推荐

三条素材里只有**待机**会受时长影响（点击/拖拽本来就是 5s）。
