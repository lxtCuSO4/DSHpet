# 桌宠管理

右键任意桌宠，选择“桌宠管理…”。也可以单击通知区的桌宠图标打开菜单，或双击图标打开设置；Windows 可能把新图标收在通知区的折叠菜单中。关闭设置窗口后，桌宠继续运行。

管理页列出配置中的全部角色，包括已关闭的原项目宠物。每张卡片显示待机预览、名字、状态和以下操作：

- 桌面显示开关：每只独立保存，允许两只或更多角色同时出现；保留原有网页显示设置。
- 显示大小：120–900 px，松开滑块后保存；“恢复默认大小”设置为 420 px。
- 找回位置：开启角色后可将它移回主屏安全区域；拖动后的位置自动记住，重启恢复时会限制在可用屏幕范围。
- 全部隐藏／恢复：临时收起所有角色，恢复时仅显示原本已开启的角色，不修改卡片开关。此临时状态不跨重启保存。

模式、开关、大小和位置保存在本机。角色配置写入前备份到用户数据目录的 `manager-backups/`；管理偏好和位置单独保存在 `desktop-manager.json`。全部角色关闭后，管理入口仍保留；该偏好文件也让宿主下次启动时继续拉起托盘。

## 显示模式

| 模式 | 行为 |
| --- | --- |
| 智能避让（默认） | 平时显示于普通窗口上方；检测到 Windows 全屏时，临时隐藏与该屏幕相交的桌宠，退出全屏后恢复。普通最大化不视为全屏。 |
| 普通窗口 | 使用普通窗口层，其它应用可以遮挡桌宠。 |
| 始终置顶 | 保持置顶，全屏时也可能显示在内容上方。 |

Windows 检测使用后台 PowerShell 5.1 子进程，每约 300 ms 读取可见窗口和屏幕矩形，不读取窗口标题或视频内容。探针启动失败、退出或失去响应时，智能模式退回普通窗口层并在管理页提示。其它系统当前也使用普通窗口层回退，不声称支持自动全屏检测。

全屏避让由窗口几何判断，有短暂检测延迟；不同播放器、独占全屏或系统浮层的行为可能不同。多屏按相交屏幕处理，测试覆盖了多屏规则，但本轮实际全屏验证仅在单屏 Windows 环境完成。

`Ctrl+Alt+P`（macOS 为 `⌘+Alt+P`）可临时隐藏／恢复。快捷键可以关闭；被其它程序占用时，页面会显示提示，仍可通过托盘和页面操作。

## 源码与已安装插件

源码构建沿用 [使用说明](../本仓库使用说明.md)。新模块位于 `runtime/electron-helper/`，不需要新增前端构建步骤；宿主源码包含全关后重新启动管理入口的条件。

本机已安装的旧版 `0.3.7` 与仓库源码有差异。兼容部署工具只修改安装目录中 `main.js`、`preload.js`、`sprite.js` 的明确接入位置，加入管理模块；不替换完整旧文件，不修改 `index.html` 的防闪帧样式。`--patch-host` 另外只修改旧安装 `lib/index.js` 的两处启动门槛，使全部关闭后重启仍保留托盘。宿主的磁盘补丁在下次宿主启动时生效，当前 helper 可通过既有重载入口启用管理功能。

先检查候选变更，确认兼容后再加 `--apply`：

```powershell
node pet-pack/deploy-desktop-manager.mjs `
  --source '<工作区>/_repo/dsh-pet/runtime/electron-helper' `
  --target '<已安装 dsh-pet>/runtime/electron-helper' `
  --backup '<本地备份目录>' --patch-host
```

工具在任何写入前备份所有将修改的既有文件，校验 JS 语法和前后哈希。重复执行相同候选不再修改；遇到不匹配的安装结构则拒绝补丁。更新插件后可能覆盖这些安装补丁，需先核对新版本差异，不能整目录覆盖或盲目重复替换。

回退时停止当前桌宠 helper，按备份清单恢复三个 helper 文件及 `host-index.js` 对应的原 `lib/index.js`，再重启宿主。新管理模块可以留在磁盘上，旧入口不再引用；个人素材及配置不属于安装文件回退范围。此前的 `index.html` 防闪帧修复保持独立。
