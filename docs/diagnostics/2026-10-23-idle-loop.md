## 原实例证据

原 Electron 主进程 PID 27980，启动于 2026-10-23 14:07:36。
安装 `index.html` 最后写入 14:07:21，`sprite.js` 最后写入 2026-10-21 19:34:58。
时间顺序不支持“本次 CSS 修改发生在进程启动以后”的推测；未直接读取原实例 CSSOM。

第一次录屏 35 秒、2,100 帧未发现额外空白。其固定角色区域与素材匹配的平均最小
RMSE 约 0.947/255，最大约 1.019/255。单次未捕获不能证明问题不存在。

第二次录屏媒体时长 124.984 秒，共 6,876 个编码帧。因后段位置和背景发生变化，
固定 ROI 比对只使用前 75 秒的 4,124 个解码帧。采样并非严格每秒 60 帧，使用实际 PTS。

| 解码帧序号（从 0 起） | PTS | 回看结果 |
| --- | --- | --- |
| 3085 | 56.200000 秒 | 角色可见，最接近素材第 237 帧（接近结尾） |
| 3086 | 56.233333 秒 | 角色完全消失，底层页面仍可见 |
| 3087 | 56.250000 秒 | 角色恢复，最接近素材第 4 帧（接近开头） |

其他循环相位回绕出现在 6.200、16.200、26.200、36.233、46.217、66.233 秒，
异常位于同一约 10 秒周期的 56.233 秒边界。
素材相近姿态可能匹配到相邻数帧，因此相位用于判断首尾，不当作精确播放时间。

主体 ROI 与原素材逐帧比较，异常帧最小 RMSE 为 62.533/255，其他帧最大 6.516/255。
色彩换算、缩放、alpha 边缘使该算法存在正常基线残差；此数值用于找异常，
“角色消失”的判断来自回看原帧。异常只占一个已捕获样本，不能据此精确断言持续 16.67 毫秒；
正常前后样本跨度为 50 毫秒。原进程没有同时记录媒体/合成事件，尚未排除 GDI 抓屏偶发漏层。

## 素材与代码核对

- 当前待机素材 VP9 alpha、960×540、24 fps、240 帧、10 秒；逐帧 alpha 总和约
  11,898,094～12,448,875，没有全透明帧或结尾 alpha 塌陷。
- 首尾差分均值约 4.79/255；片中约 5 秒有较大姿态变化，最大相邻差分 12.65/255。
  不能仅凭差分断言重绘、闪灰或素材缺陷，也不能用混帧掩盖运行时空帧。
- 安装 `sprite.js:365` 的 `switchTo` 先设置后层素材，`loadeddata` 后立即显示新层、
  隐藏并暂停旧层。`playIdle → playOnce → switchTo(..., true)`，因此 `el.loop=false`。
- `switchTo(name,false)` 的原生 loop 主要用于单候选工作状态分支，不能与普通待机混同。
- 安装版本与工作区同为 0.3.7，但内容差异较大。安装 `index.html:51` 已禁用 fade，
  工作区相应位置仍保留旧 fade；不能整文件互相覆盖。
