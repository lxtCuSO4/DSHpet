# 桌宠管理与全屏避让

用户已于 2026-10-24 确认本方案，授权制作与部署第一版。

独立管理窗口从托盘与桌宠右键菜单打开。列表覆盖成品配置中的全部角色，包含已关闭的角色；展示待机预览、名称、状态、独立桌面开关、大小（120–900，默认 420）与找回位置。开关只切换 desktop 位，保留 web 位。全部隐藏/恢复为临时操作，不修改逐只开关，快捷键默认 Ctrl+Alt+P，可关闭。所有宠物关闭后托盘和管理入口仍可用。

提供智能避让（默认）、普通窗口、始终置顶三种模式。智能模式在 Windows 检测前台可见全屏窗口，按显示器范围临时隐藏对应宠物，退出后恢复原本开启的角色。普通最大化窗口不当成全屏；自身窗口与桌面壳排除。检测异步运行于隐藏的 PowerShell 子进程，主进程不阻塞；失败在设置页显示，不虚报功能有效。非 Windows 明示不支持自动检测，仍支持普通层与置顶。隐藏状态分别记录手动开关、全部临时隐藏、全屏避让，不互相覆盖。隐藏时暂停媒体以降低消耗，恢复后继续。

管理服务与现有 host 共用同一套成品配置读取与元数据入口。新增受限的本机配置写服务，仅允许成品列表中已存在的宠物修改 size/display，定位其所属文件，保留其它配置语义、拒绝损坏文件并原子写入，写前本地备份。此服务不接受任意路径或任意配置字段。设置窗通过受限 preload IPC 调用，验证发送者，无 Node 集成、禁远程导航。素材预览继续经既有 bridge 获取，无新增网络服务。

helper 在进程内重建受影响的宠物窗口，配置索引变化时重新核对所有窗口，避免关闭一只后显示错角色。管理窗和托盘保留。位置保存于用户数据下 desktop-manager.json，与角色文件分离；更新前捕获、恢复后夹取可用屏幕区域，找回按钮回主屏安全位置。定时保存与退出落盘，失败可见。模式、快捷键和位置持久化，临时全隐藏不持久化。

界面使用暖白背景、墨色文字和青绿色强调色，角色预览区有棋盘底；窄窗纵向排列，表单都有标签和键盘焦点，保存失败回退控件并显示明确错误，不展示成功假状态。前台状态每秒刷新时不打断正在编辑的滑块与焦点。

验证涵盖真实临时文件读写、损坏配置/非法字段/重复 ID、模式状态决策、多屏范围、隐藏恢复、位置重启恢复与屏幕夹取；浏览器验证列表/开关/失败反馈/窄屏键盘；隔离 Electron 验证 IPC、托盘、0 宠物、窗口索引与普通最大化/全屏避让。部署通过受控补丁分别修改源码和安装差异位置，备份安装文件并保留已有 visibility 修复及个人素材。最后更新 AGENTS.md、使用说明，合并 main、推送 origin 并清理临时分支。
